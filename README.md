# PRIXMA

Design agency landing page built with HTML, Bootstrap, CSS and JavaScript, featuring services, projects and team sections.

<p dir="rtl">لندینگ‌پیج آژانس طراحی با بخش‌های خدمات، نمونه‌کار و معرفی تیم.</p>

[Deployment link](https://prixma.vercel.app) · [Source](https://github.com/Erfan-Ebrahimi/PRIXMA)

## Stack

HTML · CSS · Bootstrap · JavaScript

## What's inside

- Hero and service presentation
- Project, team and review sections
- Blog and contact interface

## Local setup

Serve the repository root with a local static web server, then open `index.html`. No npm build step is configured in this repository. Keep the asset folders next to the HTML files.

## Project layout

- `index.html` — landing page
- `css/` — stylesheets
- `js/` — browser scripts
- `img/` and `fonts/` — visual assets

## Project notes

A front-end practice project. Sample copy and statistics are part of the demo design, and the contact interface does not imply a working submission backend.
